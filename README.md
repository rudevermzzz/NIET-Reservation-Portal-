# 🏢 Incubation Reservation Portal

A modern web-based reservation platform designed for the **NIET Technology Business Incubator (TBI)** to simplify workspace and meeting room bookings for students, incubatees, and faculty members.

The portal provides a clean dashboard to check room availability, reserve workspaces, manage bookings, and streamline the entire reservation process through a user-friendly interface.

---

## ✨ Features

### 📅 Smart Booking System
- Reserve incubation spaces and meeting rooms
- View real-time room availability
- Time-slot based booking
- Prevent overlapping reservations

### 👥 Multi-Role Access
- Student Portal
- Faculty Portal
- Incubatee Portal
- Admin Queue

### 👤 User Profiles
- Profile switching
- Active booking dashboard
- Booking history
- Pending requests tracking

### 📊 Interactive Dashboard
- Daily room schedule
- Reservation calendar
- Workspace availability
- Booking insights

### 🏢 Room Management
- Multiple meeting rooms
- Board room support
- Room capacity display
- Room specifications
- Available facilities (Wi-Fi, Smart TV, AC, etc.)

### 🔐 Secure Reservation Workflow
- Booking requests
- Approval queue for administrators
- Conflict prevention
- Session management

### 💬 Feedback System
- Submit meeting feedback
- Improve workspace management
